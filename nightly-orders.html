The algorithm

Each evening, Python reads Alphabet daily closing prices from price_history.json, the course data feed committed to this repository. It uses the latest 21 completed exchange sessions to compare yesterday’s and today’s 5-day and 20-day simple moving averages.

If the 5-day average was at or below the 20-day average and is now above it, the algorithm submits a limit order to buy one Alphabet Class A share for the next trading session. The limit equals the latest close, rounded to cents. Every other signal produces an empty order list.

I chose this entry rule because its inputs and decisions are easy to inspect. The fast average responds to recent prices, while the slow average provides a longer comparison. Requiring a new crossover avoids a new entry every day the fast average stays above the slow average. This assignment demonstrates an entry algorithm; it has no exit rule or portfolio sizing model, and repeated crossover fills can accumulate shares. No return or profitability claim is made.

From nightly run to published orders

GitHub Actions runs at 03:00 UTC each night, matching the instructor’s schedule. That is 10pm Eastern standard time and 11pm Eastern daylight time. GitHub can delay scheduled runs. A manual run is also available.

The workflow checks out the repository, installs Python dependencies, reads the course price feed, and generates open_orders.json at the root. It writes the same list to mkt/open_orders.json to match Sanji’s current guide, commits the outputs, and requests a GitHub Pages build.

An exchange calendar chooses the latest completed session and the next valid trading date, including holidays. The course price update must finish before this workflow runs. Prices for all 21 required sessions must be present and positive. A data failure clears the order lists, publishes a failure status, and marks the workflow failed. Orders carry a specific date so an old instruction cannot roll into a later session.

Sanji’s guide currently says order resolution is still forthcoming. When supported, a limit buy fills at the open if the open is at or below the limit, or at the limit if the day’s low reaches it. Otherwise it stays unfilled. This script writes proposed orders and leaves positions and fills to Sanji. It does not check account cash or existing exposure.
